# Telegram-бот "Менеджер замовлень"

Бот приймає замовлення від клієнтів (практичні/лабораторні, реферати,
презентації), питає дані для титульної сторінки, вимоги, дедлайн і
прикріплені файли, а потім надсилає вам повне зведення у Telegram.

## 1. Встановлення

Потрібен Python 3.10+.

```bash
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## 2. Створення бота в Telegram

1. Напишіть у Telegram боту **@BotFather**
2. Команда `/newbot`, дайте назву та username (має закінчуватись на `bot`)
3. Скопіюйте виданий токен

## 3. Дізнатись свій Telegram ID

Напишіть боту **@userinfobot** — він покаже ваш числовий ID.

## 4. Налаштування

Скопіюйте `.env.example` у `.env` і заповніть:

```
BOT_TOKEN=токен_від_BotFather
ADMIN_IDS=ваш_id
```

Якщо адмінів декілька (наприклад, ви й помічник) — вкажіть через кому:
`ADMIN_IDS=111111111,222222222`

## 5. Запуск

```bash
python main.py
```

Бот почне працювати (long polling) — має бути постійно запущеним, поки
приймає замовлення. Для постійної роботи 24/7 варто розмістити на
недорогому VPS (наприклад, від 3-5 $/міс.) і запускати через `systemd`
або `screen`/`tmux`, або через Docker.

## Як це виглядає для клієнта

1. `/start` — бот вітається і пропонує обрати тип роботи
2. Клієнт відповідає на послідовні питання (ПІБ, заклад, предмет, тема,
   вимоги, дедлайн...)
3. Може прикріпити файли із завданням/методичкою
4. Бачить зведення і підтверджує відправку
5. Отримує номер замовлення; ви миттєво отримуєте повне зведення +
   усі прикріплені файли в особисті повідомлення

Клієнтські команди:
- `/start`, `/neworder` — почати нове замовлення
- `/cancel` — скасувати поточне оформлення
- `/myorders` — переглянути свої замовлення і статуси

## Команди для вас (адміна)

- `/orders` — список усіх замовлень
- `/orders new` / `/orders in_progress` / `/orders done` / `/orders cancelled` — фільтр за статусом
- `/order <номер>` — детальний перегляд конкретного замовлення
- Кнопки під повідомленням про нове замовлення: **В роботі / Виконано / Скасувати**
  — при зміні статусу клієнт автоматично отримує сповіщення

## Як додати нові питання (найважливіше!)

Все налаштування анкети — в одному файлі **`questions.py`**. Нічого
іншого редагувати не потрібно.

Приклад — додати нове поле "Мова виконання" до практичних робіт:

```python
"practical": {
    "title": "🧪 Практична / Лабораторна робота",
    "fields": [
        ...,
        {"key": "language", "question": "Якою мовою програмування виконати роботу?"},
        ...
    ],
},
```

Параметри поля:
- `key` — унікальний ідентифікатор (латиницею)
- `question` — текст питання клієнту
- `optional: True` — додає кнопку "Пропустити"
- `type: "files"` — дозволяє надсилати кілька файлів підряд (до команди `/done`)

Щоб додати нову категорію послуг (наприклад, "Курсова робота") — додайте
новий ключ у словник `CATEGORIES` за тим самим зразком.

## Структура проєкту

```
tg_order_bot/
├── main.py              — точка входу, запуск бота
├── config.py             — завантаження токена/ID з .env
├── questions.py          — 🔧 НАЛАШТУВАННЯ анкети (сюди додавати питання)
├── database.py           — робота з SQLite (замовлення, відповіді, файли)
├── keyboards.py          — inline-кнопки
├── handlers/
│   ├── order.py          — діалог із клієнтом
│   └── admin.py          — команди для адміністратора
├── requirements.txt
└── .env.example
```

## Можливі наступні кроки (на майбутнє)

- Оплата (наприклад, Monobank/LiqPay посилання після підтвердження вартості)
- Автоматичний розрахунок орієнтовної ціни за категорією/обсягом
- Дедуплікація клієнтів, історія переписки
- Вебхук замість polling + деплой на Render/Railway/VPS з systemd
